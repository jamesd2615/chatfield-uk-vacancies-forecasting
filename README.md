# UK Labour Market Vacancies — Forecasting Research

Chatfield Quantitative Research project investigating forecasting UK vacancies with ONS data and, where suitable, Indeed indicators.

## Objectives
- Assess data quality and time-series properties.
- Develop a simple forecasting benchmark and compare alternative models.
- Evaluate out-of-sample accuracy and publish reproducible findings.

## Repository layout
- `archive/`: original weekly submissions (not necessarily validated).
- `data/`: original, interim, and processed datasets (not committed by default).
- `src/`: reviewed production-oriented analysis code.
- `notebooks/`: exploration.
- `reports/`: reviewed analyst summaries.
- `results/`: approved figures and tables.
- `paper/`: manuscript drafts and final publication.
- `presentations/`: project-specific slides.
- `tests/`: validation and regression tests.

## Status
Week 1 original submissions archived. Data pipeline and final models are not yet approved. The ARIMA prototype uses synthetic data and is not a validated final model.

## Reproduction
Dependencies, data retrieval, command-line instructions and model evaluation procedures must be documented once finalised. Original archived scripts may contain local paths and should not be assumed to run unmodified.

Document licensing and redistribution permissions for ONS and Indeed data before committing any datasets.
